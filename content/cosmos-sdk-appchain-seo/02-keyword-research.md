| Candidate | Relevance to URL | Commercial intent | SERP competition (observed) | Verdict |

| **Cosmos SDK appchain development** | Exact match to URL slug `/cosmos-sdk-appchain-development` | High. | Cosmos SDK development services | High | High | Generic agency pages (Oodles, Aalpha, Vegavid). Some stale. | Strong secondary |
| Cosmos appchain development | High | Medium–High | Similar to primary; slightly more informational | Secondary (covered naturally) |
| Cosmos SDK development company | High | Very high (vendor-selection) | Company SERP with stale/broken URLs (LeewayHertz, Nadcab) | Secondary; use in title/meta modifiers and the "why ClickMasters" section |

**Rationale for the primary:**
1. It matches the URL slug and the page's specific scope (appchains, not Cosmos dApps or wallets). This keeps the page distinct from any broader "Cosmos blockchain development" or general "blockchain development" page on the site, which avoids cannibalisation.
2. It is the most specific commercial phrasing. Buyers who type "appchain" already understand they need their own chain, the bottom-of-funnel signal we want.
3. The SERP has no strong dedicated agency page; the docs and explainers hold informational positions only.
4. "Cosmos SDK development company/services" are captured as close variants in the title, H2s and meta, without a separate page.

## 6. Cannibalisation guardrails (verified against the live site, 26 Nov 2026)

**Verified conflict:** `/technologies/cosmos-blockchain-development` is live with the title **"Cosmos SDK Development Services | Clickmasters"** and H1 "Cosmos SDK Development — Custom Application Blockchains and IBC Interoperability". It already links to the target page. Two indexable ClickMasters URLs currently compete for "Cosmos SDK development services".

**Resolution adopted in this content package:**
| URL | Should own | Intent |
|---|---|---|
| /service/cosmos-sdk-appchain-development (this page) | cosmos sdk appchain development, cosmos appchain development (company), custom cosmos blockchain development, application-specific blockchain development, cosmos sdk development company, hire/IBC/validator/launch long-tails | **Commercial: "build and launch our chain"** |
| /technologies/cosmos-blockchain-development | cosmos sdk technology, what is cosmos sdk, cosmos ecosystem overview, IBC/CosmWasm explainer topics | **Informational / technology hub** |

**Recommended change on the technologies page (for ClickMasters to decide; not made by us):** retitle it to an informational title such as "Cosmos SDK Technology Overview: Modules, IBC & CosmWasm | Clickmasters". Stop using "Development Services" there, and add a prominent contextual link to this page with the anchor "Cosmos SDK appchain development services". If that page cannot change, keep "Cosmos SDK Development Services" **out of this page's title tag** and use it only in body copy and an H2. The title in 06-on-page-seo.md already follows this rule.

**Other rules:**
- **Do not target on this page:** "cosmos wallet development", "cosmos dApp development", "cosmos token development", "cosmos NFT marketplace". Link out to `/service/crypto-wallet-development`, `/service/smart-contract-development` etc. instead.
- **CosmWasm:** no dedicated CosmWasm page exists (verified 404 for /service/cosmwasm-development). Cover it here as an execution option, without building a CosmWasm sales page inside this page.
- **Polkadot/Substrate:** `/technologies/polkadot-development` owns Substrate. This page mentions Substrate only in a framework comparison and links there.
