## Key decisions
- **Primary keyword:** "cosmos sdk appchain development". It matches the URL and has the most specific commercial intent, and the SERP has no dominant agency page. "Cosmos SDK development company/services" are handled as variants.
- **Cannibalisation:** `/technologies/cosmos-blockchain-development` already uses the title "Cosmos SDK Development Services". This package positions the service page as the commercial "build and launch" page and recommends making the technologies page informational.
- **Accuracy over boilerplate:** the page reflects the 2026 stack, and several competitors are out of date on it:
  - Interchain Security retired on the Cosmos Hub
  - CometBFT v1 retracted
  - SDK v0.55
  - ibc-go v11 and IBC v2 to Ethereum
  - IBC under the Linux Foundation (LF Decentralized Trust)
  - Leap Wallet shut down
  - Enterprise module licensing
- **No fabrication.** There are no invented keyword metrics (none were available, so they are labelled estimates), no invented projects, clients, ratings, TPS figures or prices. The site has no verified Cosmos project evidence. The page uses methodology plus an anonymised reference architecture, and marks exactly what ClickMasters must supply.
